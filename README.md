🟢 Bouncing Balls

A small animation project built with HTML, CSS, and vanilla JavaScript.
It creates multiple colorful balls that move and bounce around the screen, demonstrating basic physics, collision detection, and DOM animation.

🚀 Features

Randomly generated bouncing balls

Smooth movement across the screen

Simple collision and boundary detection

Fully written in vanilla JavaScript

Fun visual animation

🧰 Tech Stack

HTML

CSS

JavaScript

📦 How to Run

Just open the index.html file in your browser:

open index.html

🎯 Purpose

This project was created to practice:

Animation in JavaScript

Working with the browser’s rendering loop

Building small visual experiments
